How to read a number

  • Events = how many times it fired. One person can count many times.
  • Users = distinct people that day. Funnel steps are user counts, not ordered sessions.
  • If a later step has more people than an earlier step, they joined from another entry (or a missing event).
  • Banknote and Coinzy are never mixed in one query.

7. Scans / user

8. Identify funnel rate (comment 5.8)

Banknote KPI: distinct success users ÷ Identify-open users (Identify_bottom_nav ∪ Identify_home), same day. Camera screen is not “open”.

Coinzy KPI: distinct success users ÷ camera users (Identification_screen ∪ photo_screen). Identify_bottom_nav also fires when camera opens from Home, so nav ∪ home is not the denominator. Success = identification_done_success ∪ Identification_done.

The step-by-step path is Funnels → Identify (tables below). Do not use tab 3 for that.
